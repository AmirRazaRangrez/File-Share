1. Overview of Service

This application provides direct, browser-to-browser peer-to-peer (P2P) file transfer using WebRTC data channels. Files transferred through this service travel directly between the sender and receiver devices. At no point are your files uploaded to, stored on, processed by, or cached on our servers.

2. Architecture and Data Privacy

Signaling: Our server acts solely as a temporary signaling coordinator to establish the initial connection between two browsers. Only metadata required for the network handshake (such as session connection descriptions and network candidate addresses) is relayed.

Zero Storage: No file content, file names, or user data are saved to disk or persistent storage on any server. Once the peer connection is established, the signaling server does not intercept the file stream.

End-to-End Encryption: All transfers via WebRTC are encrypted in transit by default using DTLS (Datagram Transport Layer Security) and SCTP protocols.
